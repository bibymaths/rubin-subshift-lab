# Symbolic dynamics

For a finite alphabet $A$, the full one-dimensional shift is $(A^{\mathbb Z})$. A point is bi-infinite, while a finite word belongs to \(A^n\). The left shift is

$$
(\sigma x)_i = x_{i+1}.
$$

The laboratory never stores a generic bi-infinite point. It works with finite words, graph presentations, and points of \(A^{\mathbb Z/n\mathbb Z}\). A stored length-\(n\) quotient point can have least period properly dividing \(n\); the API reports both concepts separately.
