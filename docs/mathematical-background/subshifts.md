# Subshifts

A subshift \(X\subseteq A^{\mathbb Z}\) is closed and shift invariant. A finite forbidden list defines the points containing none of those blocks. A one-step shift of finite type is represented by a zero-one matrix \(M\), where \(M_{ij}=1\) permits symbol \(j\) after symbol \(i\).

For a one-step SFT, the number of points fixed by \(\sigma^n\) is

\[
|\operatorname{Fix}(\sigma^n)|=\operatorname{tr}(M^n).
\]

For the golden mean matrix \(\begin{pmatrix}1&1\\1&0\end{pmatrix}\), the first counts are \(1,3,4,7,11\). These are periodic-quotient point counts, not finite-word counts.
