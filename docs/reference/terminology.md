# Terminology

| Term | Meaning in this project |
| --- | --- |
| Word of length \(n\) | An element of \(A^n\) with no cyclic boundary implied |
| Period-\(n\) quotient point | An element of \(A^{\mathbb Z/n\mathbb Z}\) |
| Least period | Smallest positive shift fixing a quotient point |
| Endomorphism | Shift-commuting continuous self-map; invertibility not assumed |
| Automorphism | Invertible endomorphism |
| Finite permutation image | Restriction of selected automorphisms to a finite invariant set |
| Bounded exhaustive search | Complete only inside declared parameter bounds |
| Reconstruction signature | Selected finite invariant vectors plus reproducibility metadata |
