# Subshift Designer

Choose a built-in full shift or one-step SFT, set finite word and period bounds, and inspect:

- the transition graph and adjacency matrix;
- admissible finite-word counts;
- periodic-quotient point counts;
- exact tabular exports and interactive figures.

The golden mean example forbids `11`. Its finite-word count and periodic-point count are different sequences; the interface labels them separately.
