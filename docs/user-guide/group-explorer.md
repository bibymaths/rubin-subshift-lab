# Automorphism Group Explorer

The group page restricts the left or right shift to all configurations of a selected finite period. It then:

1. validates that the action is a permutation;
2. enumerates generator closure up to a declared cap;
3. reports whether closure completed;
4. computes action orbits and element orders;
5. displays finite distributions and cycle notation.

The enumerated object is a finite image of the selected generators, not the full automorphism group.
